# G-Retag for QuickTime 바뀐 점 (예전 이름 G-ColorTag)

## 3.12.1
- 앱을 켜고 화면이 뜬 직후에 끄면 한동안 앱이 끝나지 않고 멈춘 것처럼 보이던 문제를 고쳤습니다.
  (켤 때 걸어 둔 확인 타이머가 끝날 때까지 앱 종료를 붙잡고 있었습니다. 이제 창을 닫으면 바로 끝납니다.)

## 3.12.0
- 원본 직접 재생: 미리보기를 720p 로 다시 만들지 않고 원본 영상을 그대로 재생합니다. 원본 해상도로 보이고, 영상을 고르면 기다림 없이 바로 재생됩니다.
  태그만 다른 모습은 영상을 복사하지 않는 아주 작은 참조 파일로 보여 주며, 실제 저장본과 밝기가 같습니다.
- 소리 재생: 영상의 소리가 납니다. '소리 켬/끔' 버튼이나 M 키로 바꾸고, 다음에 켤 때도 기억합니다.
- 원본 직접 재생이 안 되는 영상은 예전처럼 720p 미리보기(소리 없음)로 자동 전환됩니다.

## 3.11.0
- 확인 뷰어 기능: 파인더에서 영상을 '다음으로 열기'로 열거나 Dock 의 앱 아이콘에 끌어다 놓으면 바로 목록에 들어갑니다.
- 프레임 단위 이동(‹ › 버튼, ← → 키, Shift 와 함께 10프레임)과 타임코드 표시(파일의 시작 타임코드 기준, 드롭 프레임 지원).
- ↑ ↓ 키로 목록의 영상을 연달아 넘겨 볼 수 있습니다. Space 는 어디에 포커스가 있어도 재생·멈춤입니다.

## 3.10.0
- GRAY ZONE 공통 디자인 규칙 적용: 우상단 `© GRAY ZONE` 표기(태그 안내 화면 포함), 글꼴 Pretendard (런치 화면의 큰 GRAY ZONE 글자는 Manrope),
  버튼·목록 선택 상태·진행 막대·오류 표시를 공통 표준에 맞췄습니다.
- 달라진 동작: 영상 그림을 누르면 재생·멈춤이 아니라 그쪽이 선택됩니다. 재생과 멈춤은 재생 버튼과 Space 키로 합니다.
- 달라진 동작: 저장을 끝낸 영상은 목록에 있는 동안 다시 저장하지 않습니다 (목록을 비우고 다시 넣으면 새로 저장됩니다). 모두 저장하면 버튼이 "모두 저장했어요"로 바뀝니다.
- 저장 버튼의 개수는 실제로 저장될 영상만 세고, 건너뛰는 개수를 아래에 알려 줍니다.
- 저장 실패 문구가 잘리지 않고 끝까지 보이며, 영어 오류 원문 대신 원인과 할 일을 우리말로 알려 줍니다. 저장 중에는 진행 막대가 보입니다.
- 가장 작은 창에서도 태그 안내의 [시작하기] 버튼이 늘 보입니다.
- 런치 화면: 글꼴과 내용이 준비된 뒤에 창이 나타나고, 런치 화면이 먼저 그려진 다음에 메인 화면을 불러옵니다 (런치 창이 몇 초 동안 검게 보이던 문제 수정). 준비 중 오류로 멈추면 클릭하거나 키를 눌러 앱을 닫을 수 있습니다.
- 사이드바 아래의 저작권 문장은 정보 창으로 옮겼고, 화면 표기는 "GRAY ZONE"으로 통일했습니다.

## 3.9.0
- 메인 화면을 런치 화면과 같은 디자인으로 맞췄습니다: 배경 #121212, 무채색 화면, Inter / Noto Sans KR 글꼴, 각진 형태.
- 강조 아이콘에만 색을 씁니다 (✓ 완료, ⚠ 주의, ✕ 실패, 현재 단계 번호, 새 버전 표시). 글자·버튼·테두리는 무채색입니다.
- 위쪽 로고를 실제 앱 아이콘으로 바꿨습니다.

## 3.8.0
- GRAYZONE 공통 런치 화면: 앱을 켜면 640×400 런치 화면이 뜨고, 아래 회색 11칸(존 0–X)이 실제 준비 단계에 맞춰 채워진 뒤 메인 창으로 넘어갑니다.
  준비 중 문제가 생기면 무엇이 실패했는지 런치 화면에 표시합니다.
- 태그 안내는 메인 창에서 그대로 보여 줍니다.

## 3.7.0
- 처음 쓰는 분도 알기 쉽게 화면과 문구를 다듬었습니다 (태그·색 과학을 몰라도 쓸 수 있게).
- 로딩 화면: "맥 퀵타임에서 밝고 뿌옇게 보이나요?"처럼 증상부터 설명하고, 원리는 '자세히 보기(컬러리스트용)'로 접었습니다.
- 두 화면에 쉬운 설명을 붙였습니다: 퀵타임에서 밝고 옅게 보이는 상태 / 색보정실 모니터와 같게 보이는 상태(맥 퀵타임 전달용 추천).
- 순서 표시(① 영상 넣기 → ② 두 화면 비교 → ③ 고르고 저장)와 빈 화면의 큰 끌어다 놓기 영역.
- '크게 번갈아 보기' 버튼, 비교 팁, 저장 버튼 옆 "원본은 건드리지 않아요" 안내, MP4 → MOV 저장 안내.
- 목록·저장 결과를 쉬운 말로: "퀵타임에서 밝게 보임", "저장 완료 · 퀵타임에서 정확하게 보입니다", '퀵타임으로 열기' 버튼.

## 3.6.0
- 이름 변경: G-ColorTag → G-Retag (부제목 for QuickTime). 자동 업데이트로 받으면 앱이 처음 켜질 때 스스로 G-Retag 로 이름을 바꿉니다.
- 로딩 화면: 앱이 켜지는 동안 태그 안내(태그의 뜻, 태그를 바꿔도 픽셀 밝기는 그대로)를 보여 주고, 플레이어 준비와 업데이트 확인을 합니다.
  '다음부터 안내 없이 바로 시작'을 고를 수 있고, 위쪽 '태그 안내' 버튼으로 다시 볼 수 있습니다.
- 뷰어 이름: 왼쪽 Rec709 1-1-1 (General), 오른쪽 Rec709 1-2-1 (For Mac QuickTime).
- 업데이트 알림창: 새 버전이 있으면 바뀐 점·내려받기 진행을 보여 주고 '지금 다시 시작' 또는 '나중에'(끌 때 설치)를 고를 수 있습니다.

## 3.5.0
- 1-2-1 저장 수정: 퀵타임 '동영상 속성'에 전송 기능 '지정 안 됨', 코드 포인트 '(1-2-1)'로 보이게 저장합니다.
  1-2-1 태그에 감마 2.4 표시(gama)를 함께 넣습니다 (베이스라이트 자동 태그와 같은 방식). 감마 표시는 MOV 에만 들어가므로 1-2-1 은 MOV 로 저장합니다.
  이전 버전은 '태그가 달리지 않음'으로 보였습니다.
- 저장 후 확인 문구 수정: 퀵타임에서 '태그가 달리지 않음'으로 보이면 그대로 알려 줍니다.

## 3.4.1
- 전체화면 수정: 영상 뒤의 다른 화면·목록이 비쳐 보이던 문제를 고쳤습니다.
- 저장 후 확인: 저장한 파일을 퀵타임과 같은 방식으로 다시 읽어 (1-2-1) 인지 목록에 표시합니다.
- 문제 진단: 원본과 저장본의 색 정보 구조를 기록 파일(~/Library/Logs/G-ColorTag.log)에 남깁니다.

## 3.4.0
- 미리보기를 퀵타임과 같은 엔진(AVFoundation)으로 재생: 1-1-1 과 1-2-1 의 밝기 차이가 퀵타임 플레이어와 똑같이 보입니다.
- 저작권 표시: 이 앱의 저작권은 GRAYZONE 에 있습니다 (앱 화면·정보 창·설치 안내).
- 끌어다 놓기: 영상 파일이나 폴더를 창에 끌어다 놓으면 목록에 추가됩니다.

## 3.3.0
- 자동 업데이트: 새 버전을 뒤에서 받아 두고, 앱을 끄거나 '지금 다시 시작'을 누르면 바꿔 넣습니다.
- 플레이어 전체화면: 각 화면의 ⛶ 버튼으로 크게 보고, Tab으로 1-1-1 ↔ 1-2-1 을 바로 바꿔 볼 수 있습니다.

## 3.2.0
- 태그 안내 문구 정리: 1-1-1 일반 Rec709, 1-2-1 맥 퀵타임에서 정확하게 보이는 Rec709.
