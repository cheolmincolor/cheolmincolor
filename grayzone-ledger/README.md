# GRAYZONE 장부

구글 시트 「GRAYZONE 매출 장부」에 붙여 쓰는 경리용 웹앱입니다. 폰·PC 브라우저에서 주소 하나로 엽니다.

- **요약** — 연도별 매출·미수금, 월별 차트와 표(전년 대비), 거래처 매출 상위
- **장부** — 월별 작업 목록, 검색(전체 연도), 등록·수정·삭제
- **미수금** — 오래된 순·금액순·거래처별, 계산서 발행·입금 처리(전액/일부)를 버튼으로

앱은 「장부」 시트의 A~P열(입력 칸)만 읽고 씁니다. 연도·월·미수금(Q~S열)과 요약·미수금·거래처별 시트는
지금처럼 시트 수식이 계산하므로, 앱에서 넣은 내용과 시트에서 직접 넣은 내용이 똑같이 반영됩니다.

## 설치 (한 번만, 5분)

1. 「GRAYZONE 매출 장부」 시트를 열고 **확장 프로그램 > Apps Script** 를 누릅니다.
2. 왼쪽 `Code.gs` 의 내용을 모두 지우고 이 폴더의 [`Code.gs`](Code.gs) 내용을 붙여 넣습니다.
3. 파일 옆 **+ > HTML** 을 눌러 이름을 `Index` 로 만들고, [`Index.html`](Index.html) 내용을 붙여 넣습니다.
4. 저장(💾)한 뒤 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만**
5. **배포** 를 누르고, 처음 한 번 나오는 권한 요청을 허용합니다(이 시트 하나에만 접근합니다).
6. 나온 **웹 앱 URL** 을 즐겨찾기에 넣습니다. 폰에서는 브라우저 메뉴의 **홈 화면에 추가** 로 앱처럼 씁니다.

코드를 고친 뒤에는 **배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포** 를 해야 같은 주소에 반영됩니다.

## 시트에 쓰는 규칙

| 앱에서 하는 일 | 시트에 일어나는 일 |
|---|---|
| 작업 등록 | 납품일의 연도·월 묶음에서 첫 빈 행에 입력. 빈 행이 없으면 그 묶음 끝에 행을 삽입 |
| 계산서 발행 | 계산서 = `완료` |
| 입금 처리 · 전액 | 지급 = `완료`, 입금일 입력 |
| 입금 처리 · 일부 | 입금액 = 지금까지 받은 금액, 입금일 입력 (미수금 = 견적금액 − 입금액) |
| 수정 | 바꾼 칸만 씀. 납품일을 다른 달로 바꾸면 그 달 묶음으로 옮김 |
| 삭제 | 그 행의 입력 내용만 지움(빈 행은 다음 등록 때 다시 쓰임) |

- 장부에 없는 연도(예: 2028년)로는 등록되지 않습니다. 시트에 그 연도·월 묶음을 먼저 만들어 주세요.
- 앱을 열어 둔 사이 시트에서 행을 삽입·정렬해 행이 밀렸으면, 저장할 때 "장부가 그 사이에 바뀌었습니다"라고
  알리고 아무것도 쓰지 않습니다. ↻ 를 누른 뒤 다시 하면 됩니다.
- 계산서 발행·입금 처리는 직후에 뜨는 알림의 **되돌리기** 로 취소할 수 있습니다.

## 테스트

Apps Script 없이 가짜 시트(지어낸 데이터)로 서버 로직과 화면을 끝까지 돌려 봅니다. Node 22 이상과 Playwright 가 필요합니다.

```sh
node --test test/*.test.js
```
