# 바뀐 점

새 버전을 올릴 때 `package.json` 의 version 을 올리고 맨 위에 그 버전의 내용을 적습니다.
여기 적은 내용이 앱의 업데이트 안내와 GitHub 릴리스에 그대로 나옵니다.

## 1.10.0

- 릴리스 주소의 이름을 `g-account-v버전`으로 바꿨습니다(1.9.0까지는 `ledger-v버전`). 자동 업데이트는 그대로 동작합니다.

## 1.9.0

- 요약에 「연간 흐름」 추가: 가로 1~12월, 세로 1~5주. 칸이 밝을수록 그 주의 매출이 크고, 미수가 남은 주는 ⚠. 칸을 누르면 그 주의 작업이 열립니다.
- 미수금: 「최신순」 보기를 추가하고 처음 보이는 순서로 했습니다(가장 최근에 납품한 미수금이 위). 월별·금액순·거래처별은 그대로 고를 수 있습니다.

## 1.8.0

- GRAY ZONE 공통 디자인 규칙 적용: 화면을 무채색으로, 상태는 기호(완료 ✓ · 주의 ⚠ · 실패 ✕)와 굵기·외곽선으로 표시. 기호에만 색을 씁니다.
- 글꼴을 Pretendard로 바꿔 내장. 런치 화면의 큰 GRAY ZONE 글자는 Manrope.
- 메인 화면 우상단에 `© GRAY ZONE` 표기. 런치 화면에 이 앱의 존 번호 IX 표시.

### 사용성 검수 반영

- 대화상자의 주 버튼(저장·등록) 글자가 보이지 않던 문제 수정. 저장 중에는 「저장하는 중…」 표시
- 「전액 입금」에서 금액 칸이 보이던 문제, 미수금이 없을 때 배지가 보이던 문제 수정
- 넓은 창에서 알림이 머리줄을 가리지 않음. 오류 알림은 ✕ + 굵은 글자
- 입력 창의 오류 줄이 입력 칸을 덮지 않고, 입력을 고치면 사라짐
- 입력한 내용이 있으면 바깥을 눌러도 닫히지 않고, Esc·취소는 한 번 물어봄
- 삭제: 무엇을 지우는지 보여 주고 0.6초 뒤에야 「정말 삭제」가 눌림(5초 지나면 원래대로)
- 불러오기에 실패한 화면에서 탭을 눌러도 오류 안내가 남음
- 처음 설정 화면의 안내가 가려지지 않고, 로그인 대기 안내는 오류처럼 보이지 않음
- 가장 작은 창 너비를 500으로, 파란 기본 색(선택·체크) 제거, 줄바꿈은 단어 단위
- 런치 화면이 오류로 멈추면 아무 곳이나 누르거나 키를 눌러 닫음
- 오류 알림을 어두운 바탕 + 외곽선 + ✕ 로, 새 버전 안내 막대가 있으면 그 아래에 표시
- 입력 중에는 메뉴 단축키(⌘1~3, ⌘,)로도 확인 없이 닫히지 않음. 자동완성 목록은 Esc 한 번으로 목록만 닫힘
- 날짜 칸의 파란 선택색 제거
- 보이는 표기를 「GRAY ZONE」으로 통일, Manrope 라이선스 원문으로 교체

## 1.7.0

- 앱을 열 때의 화면을 GRAYZONE 공통 런치 화면 규격으로 바꿨습니다(640×400, 무채색, 11칸 웨지가 로딩 진행을 겸함).
- 웨지는 실제 단계에 맞춰 찹니다: 설정 읽기 → 업데이트 확인 → 새 버전 받기 → 장부 창 준비 → 장부 읽기. 장부를 다 읽은 뒤에 창이 열립니다.
- 업데이트 확인이 실패하면 한 줄로 알리고 계속 진행합니다. 「업데이트 건너뛰고 열기」 버튼은 없앴습니다.

## 1.6.0

- 미수금 화면도 달마다 접고 펼 수 있습니다. 오래된 달이 위에 오고, 처음에는 가장 오래된 달만 펼쳐 있습니다.
- 접힌 줄에 그달 미수 건수·금액과 90일 넘은 건수가 보입니다. 「금액순」「거래처별」 보기는 전처럼 모두 보여 줍니다.

## 1.5.0

- 앱 이름을 **G-Account**로 바꿨습니다(창 제목, 메뉴, 업데이트 확인 창). 로그인·시트 연결은 그대로입니다.
- 이미 설치한 Mac 앱은 파일 이름이 「GRAYZONE Ledger」로 남아 있을 수 있습니다. Finder에서 「G-Account」로 바꿔도 됩니다.

## 1.4.0

- 버튼과 글씨를 키웠습니다(누르는 곳 40px 안팎, 보조 글씨 13px 이상).
- 넓은 창에서 「+ 작업 등록」을 위쪽 탭 줄로 옮겨 목록을 가리지 않습니다. 아이콘 옆에 이름(시트·새로 고침·설정)이 보입니다.
- 장부를 스크롤해도 달 머리줄이 위에 붙어 따라옵니다.
- 긴 등록·수정 창에서도 저장 버튼이 늘 보입니다.
- 키보드: Enter로 저장, ⌘F(Ctrl+F) 또는 /로 장부 검색. 마지막에 보던 탭을 기억합니다.

## 1.3.0

- 장부 화면을 달마다 접고 펼 수 있게 바꿨습니다. 처음에는 가장 최근 달만 펼쳐 있고, 달 이름을 누르면 열리고 닫힙니다.
- 「모두 펼치기 / 모두 접기」 버튼, 펼친 달은 다음에 열어도 그대로입니다.
- 접힌 줄에도 그달 건수·매출·미수가 보입니다. 검색·미수·계산서 미발행 보기는 찾은 것을 모두 펼쳐 보여 줍니다.
