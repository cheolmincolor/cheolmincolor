# G-Account

구글 시트 「GRAYZONE 매출 장부」와 연결해 쓰는 경리용 데스크톱 앱입니다. Mac과 Windows에서 동작합니다.

- **요약**: 연도별 매출·미수금, 월별 차트와 표(전년 대비), 분기별 부가세, 거래처 매출 상위
- **장부**: 월별 작업 목록, 검색(전체 연도), 등록·수정·삭제, 장부 점검
- **미수금**: 오래된 순·금액순·거래처별 보기, 계산서 발행과 입금 처리(전액/일부) 버튼
- **연도 묶음**: 11월이 되면 다음 해 연도·월 묶음을 시트에 자동으로 만듭니다

앱은 「장부」 시트의 A~P열(입력 칸)만 읽고 씁니다. 연도·월·미수금(Q~S열)과 요약·미수금·거래처별 시트는
지금처럼 시트 수식이 계산합니다. 그래서 앱에서 넣은 내용과 시트에서 직접 넣은 내용이 똑같이 반영됩니다.

## 설치는 세 단계입니다

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 1 | Google Cloud에서 「OAuth 클라이언트」 파일 만들기 | 15분, 처음 한 번 |
| 2 | 앱 받아서 설치 | 3분 |
| 3 | 앱에서 파일 고르기 → 구글 로그인 → 시트 주소 붙여넣기 | 2분, 처음 한 번 |

1단계는 앱이 내 구글 계정으로 시트를 읽고 쓰도록 허락받는 「출입증」을 만드는 과정입니다.
비용은 들지 않습니다. 구글 화면의 메뉴 이름은 가끔 바뀌므로, 아래와 다르면 비슷한 이름을 찾아 주세요.

### 1단계: OAuth 클라이언트 파일 만들기 (처음 한 번)

매출 장부 시트를 가진 구글 계정으로 진행합니다.

**① 프로젝트 만들기**

1. [console.cloud.google.com](https://console.cloud.google.com)에 접속합니다. 처음이면 약관에 동의합니다.
2. 위쪽의 프로젝트 선택 상자를 누르고 **새 프로젝트**를 누릅니다.
3. 이름을 `GRAYZONE 장부`로 적고 **만들기**를 누릅니다. 만든 뒤 그 프로젝트가 선택되어 있는지 확인합니다.

**② Google Sheets API 켜기**

1. 위쪽 검색창에 `Google Sheets API`를 입력해 들어갑니다.
2. **사용** 버튼을 누릅니다.

**③ 동의 화면 설정** (로그인할 때 보이는 화면입니다)

1. 왼쪽 메뉴에서 **API 및 서비스 > OAuth 동의 화면**으로 들어갑니다. 「Google 인증 플랫폼」으로 표시될 수도 있습니다.
2. **시작하기**를 누르고 다음과 같이 입력합니다.
   - 앱 이름: `GRAYZONE 장부`
   - 사용자 지원 이메일: 내 이메일
   - 대상: **외부**
   - 연락처 이메일: 내 이메일
3. 동의하고 **만들기**를 누릅니다.
4. **대상**(Audience) 메뉴에서 게시 상태의 **앱 게시**를 누르고 확인합니다.
   - 게시하지 않고 「테스트」 상태로 두면 **7일마다 로그인이 풀립니다.** 꼭 게시하세요.
   - 게시해도 다른 사람에게 공개되지 않습니다. 파일과 로그인 정보는 나만 갖고 있습니다.

**④ 클라이언트 만들기**

1. **클라이언트** 메뉴(또는 **사용자 인증 정보 > + 사용자 인증 정보 만들기 > OAuth 클라이언트 ID**)로 들어갑니다.
2. 애플리케이션 유형은 **데스크톱 앱**, 이름은 `GRAYZONE 장부 앱`으로 하고 **만들기**를 누릅니다.
3. 나오는 창에서 **JSON 다운로드**를 눌러 `client_secret_….json` 파일을 받습니다.
   창을 닫았다면 클라이언트 목록에서 그 항목을 열어 다시 받을 수 있습니다.

이 파일은 「출입증 양식」이라 다른 사람에게 보내지 않는 것이 좋습니다. 다만 이 파일만으로는 시트에 접근할 수 없고,
실제 접근은 3단계의 구글 로그인으로 허락됩니다.

### 2단계: 앱 받아서 설치

GitHub의 [릴리스 페이지](https://github.com/cheolmincolor/cheolmincolor/releases)에서 가장 위의 「G-Account 1.x.x」를 열고,
아래쪽 **Assets**에서 내 컴퓨터용 파일을 받습니다. GitHub 로그인은 필요 없습니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Mac (Apple Silicon, M1 이후) | `G-Account-버전-mac-arm64.zip` |
| Mac (Intel) | `G-Account-버전-mac-x64.zip` |
| Windows (64비트) | `G-Account-버전-windows-x64.zip` |

어떤 Mac인지는  메뉴 > 이 Mac에 관하여에서 확인합니다. 「칩」에 Apple M…이 보이면 Apple Silicon입니다.
처음 한 번만 받으면 됩니다. 그다음부터는 앱이 스스로 업데이트합니다(아래 「자동 업데이트」).

**Mac**

1. 받은 zip을 엽니다(Safari는 자동으로 풀어 줍니다).
2. `G-Account.app`을 **응용 프로그램** 폴더로 옮깁니다. 자동 업데이트가 되려면 꼭 이 폴더에 두세요.
3. 처음 열 때 「확인되지 않은 개발자」 경고가 나오면:
   - 앱을 **오른쪽 클릭 > 열기 > 열기**를 누르거나,
   - **시스템 설정 > 개인정보 보호 및 보안**의 아래쪽에서 **그래도 열기**를 누릅니다.

   Apple 개발자 계정으로 공증하지 않은 앱이라 나오는 경고이고, 처음 한 번만 하면 됩니다.

**Windows**

1. 받은 zip의 압축을 풉니다. `GRAYZONE Ledger` 폴더가 나옵니다.
2. 그 폴더를 **문서** 폴더 등 내 계정 안에 둡니다. `C:\Program Files`처럼 관리자 권한이 필요한 곳에 두면 자동 업데이트가 안 됩니다.
3. 폴더 안의 `GRAYZONE Ledger.exe`를 실행합니다.
4. 「Windows의 PC 보호」 창이 나오면 **추가 정보 > 실행**을 누릅니다. 서명하지 않은 앱이라 나오는 경고입니다.
5. 작업 표시줄의 앱 아이콘을 오른쪽 클릭해 **작업 표시줄에 고정**하면 다음부터 편합니다.

### 3단계: 앱에서 연결하기 (처음 한 번)

앱을 열면 세 칸짜리 설정 화면이 나옵니다.

1. **파일 고르기…**를 눌러 1단계에서 받은 `client_secret_….json`을 고릅니다.
2. **브라우저에서 로그인**을 누릅니다. 브라우저가 열리면:
   1. 매출 장부 시트를 가진 계정을 고릅니다.
   2. 「Google에서 확인하지 않은 앱」 화면이 나오면 **고급 > GRAYZONE 장부(으)로 이동(안전하지 않음)**을 누릅니다.
      내가 만든 앱이라 구글의 심사를 받지 않아서 나오는 화면입니다.
   3. 권한 목록에서 **Google 스프레드시트 보기, 수정…** 항목에 **꼭 체크**하고 **계속**을 누릅니다.
   4. 「로그인했습니다」가 보이면 브라우저 창을 닫고 앱으로 돌아옵니다.
3. 브라우저에서 「GRAYZONE 매출 장부」 시트를 열고, 주소창의 주소를 복사해 붙여 넣은 뒤 **연결**을 누릅니다.

요약 화면이 나오고 「2026년 매출」이 시트 요약과 같으면 설치가 끝난 것입니다.

**첫 사용 확인 (추천)**

1. **+ 작업 등록**으로 테스트 1건을 넣습니다(예: 오늘 날짜, 거래처 `테스트`, 금액 `1000`).
2. 시트에서 그 달 묶음에 들어갔는지 확인합니다. 머리줄의 ▦ 버튼을 누르면 시트가 브라우저로 열립니다.
3. 앱에서 그 건을 눌러 **수정 > 삭제 > 정말 삭제**로 지웁니다.

## 쓰는 법

| 앱에서 하는 일 | 시트에 일어나는 일 |
|---|---|
| 작업 등록 | 납품일의 연도·월 묶음에서 첫 빈 행에 입력합니다. 빈 행이 없으면 그 묶음의 마지막 행 아래에 행을 삽입합니다(서식·드롭다운·묶음이 따라옵니다). |
| 계산서 발행 | 계산서 = `완료` |
| 입금 처리 · 전액 | 지급 = `완료`, 입금일 입력 |
| 입금 처리 · 일부 | 입금액 = 지금까지 받은 금액, 입금일 입력 (미수금 = 견적금액 − 입금액) |
| 수정 | 바꾼 칸만 씁니다. 납품일을 다른 달로 바꾸면 그 달 묶음으로 옮깁니다. |
| 삭제 | 그 행의 입력 내용만 지웁니다. 빈 행은 다음 등록 때 다시 쓰입니다. |

- 계산서 발행·입금 처리는 직후에 뜨는 알림의 **되돌리기**로 취소할 수 있습니다.
- 장부에 없는 연도(예: 2028년)로는 등록되지 않습니다. 시트에 그 연도·월 묶음을 먼저 만들어 주세요.
- 앱을 열어 둔 사이 시트에서 행을 삽입·정렬해 행이 밀렸으면, 저장할 때 「장부가 그 사이에 바뀌었습니다」라고
  알리고 아무것도 쓰지 않습니다. ↻(새로 고침)를 누른 뒤 다시 하면 됩니다.

### 부가세

견적금액은 **부가세 별도**로 봅니다. 예를 들어 견적금액이 3,000,000원이면 공급가 3,000,000원, 부가세 300,000원, 합계 3,300,000원입니다.
부가세는 원 미만을 버립니다.

- **시트**: 「장부」 끝의 T~V열(공급가·부가세·합계, 회색 글씨)은 자동 계산입니다. 「부가세」 탭에서 B4의 연도를 고르면
  분기별 공급가·부가세·합계와 계산서 미발행 건이 보입니다.
- **앱**: 요약 화면의 「부가세」 표에 같은 내용이 나옵니다. 등록 창에서는 견적금액 아래에 부가세와 합계가 바로 보이고,
  미수금 화면에는 부가세를 포함한 받을 돈이 함께 나옵니다.
- **납품일 기준**입니다. 실제 신고는 세금계산서 작성일 기준이니 날짜가 다른 건은 신고 때 확인하세요.
- 견적금액에 부가세가 들어 있는 방식으로 바꾸려면 「부가세」 탭 B5(또는 앱의 설정)에서 「부가세 포함」을 고릅니다.

### 장부 점검

고칠 만한 행을 찾아 장부 화면의 **점검** 칸에 모아 보여 줍니다. 요약 화면 위쪽에도 건수가 뜹니다. 시트는 바꾸지 않습니다.

| 찾는 것 | 예 |
|---|---|
| 견적금액이 비어 있음 | 금액을 아직 안 적은 건 |
| 견적금액이 0인데 「서비스」가 아님 | 서비스 표시를 빠뜨린 건 |
| 입금액이 견적금액보다 많음 | 금액 오타 |
| 입금일은 있는데 지급 완료도 입금액도 없음 | 지급 「완료」를 빠뜨린 건 |
| 납품일이 날짜가 아님 / 다른 달 묶음에 들어 있음 | 2026-03 묶음에 4월 날짜 |
| 거래처·내용이 비어 있음, 납품일이 60일 넘게 뒤 | 연도 오타(2062년 등) |
| 날짜·거래처·내용·금액·비고가 똑같은 행 | 두 번 입력한 건 (계약금/잔금처럼 비고가 다르면 따로 봅니다) |

맞는 내용이면 그 건을 열어 **문제없음**을 누르면 목록에서 빠집니다. 설정에서 다시 볼 수 있습니다.

### 앱을 열 때: 런치 화면

앱을 열면 GRAY ZONE 공통 런치 화면(640×400)이 먼저 뜹니다. 아래쪽 11칸 웨지가 로딩 진행을 겸하고, 그 아래에 지금 하는 일이 한 줄로 나옵니다.

| 웨지 | 단계 |
|---|---|
| 1칸 | 설정 읽기 |
| 3칸 | 업데이트 확인 |
| 8칸 | 새 버전 받기(받는 만큼 참). 다 받으면 설치하고 앱을 다시 시작합니다 |
| 10칸 | 장부 창 준비 |
| 11칸 | 장부 읽기. 끝나면 장부 창이 열립니다 |

- 업데이트 확인이 실패하면(인터넷 끊김 등) 한 줄로 알리고 계속 진행합니다.
- 설정을 읽지 못하는 것처럼 앱을 쓸 수 없는 오류는 무엇이 실패했는지 적고 멈춥니다. 그때는 아무 곳이나 누르거나 키를 누르면 앱이 닫힙니다.
- 화면 규격은 모든 GRAY ZONE 앱 공통이라 수치를 임의로 바꾸지 않습니다. 이 앱의 존 번호는 IX(왼쪽에서 10번째 칸)이고 `app/splash.js`의 `APP_ZONE`에 있습니다.

### 자동 업데이트

- 앱을 열 때(런치 화면), 그리고 켜 둔 동안 6시간마다 새 버전이 있는지 GitHub 릴리스를 확인합니다.
- 받은 파일이 올린 파일과 같은지(SHA-256) 확인한 뒤에만 설치합니다.
- 켜 둔 동안 받은 업데이트는 화면 위에 「새 버전 준비됨」으로 알리고, **지금 다시 시작**을 누르거나 앱을 끌 때 적용합니다.
- 설정의 **업데이트** 칸에서 지금 버전과 바뀐 점을 보고, 직접 **업데이트 확인**을 누를 수도 있습니다.
- 로그인·시트 연결·설정은 그대로 유지됩니다.
- 「쓸 권한이 없어 바꿔 넣을 수 없습니다」가 뜨면, 앱을 Mac은 응용 프로그램 폴더, Windows는 문서 폴더 등으로 옮겨 주세요.

1.0.0(자동 업데이트가 없던 버전)을 쓰고 있다면 최신 버전만 위 2단계대로 한 번 직접 받아 바꿔 주세요.

| 증상 | 해결 |
|---|---|
| 「7일마다」 로그인하라고 나옴 | 1단계 ③-4의 **앱 게시**를 하지 않은 상태입니다. 게시한 뒤 앱에서 다시 로그인하세요. |
| 「스프레드시트 권한이 허용되지 않았습니다」 | 로그인할 때 스프레드시트 항목의 체크가 빠졌습니다. 다시 로그인하면서 체크하세요. |
| 「이 시트를 열 권한이 없습니다」 | 시트 주인이 아닌 계정으로 로그인했습니다. ⚙ 설정 > 로그아웃 후 맞는 계정으로 로그인하세요. |
| 「「장부」 시트가 없습니다」 | 다른 스프레드시트의 주소를 붙여 넣었습니다. 매출 장부 시트의 주소인지 확인하세요. |
| 「웹 애플리케이션 유형의 클라이언트입니다」 | 1단계 ④에서 유형을 **데스크톱 앱**으로 다시 만들어 그 JSON을 고르세요. |
| 「Access blocked」/「access_denied」 | 1단계 ③에서 대상이 「내부」로 되어 있거나 게시가 안 된 경우입니다. 「외부」 + 앱 게시로 바꾸세요. |
| Mac에서 「손상되었기 때문에 열 수 없습니다」 | 터미널에서 `xattr -cr "/Applications/G-Account.app"`를 실행한 뒤 다시 엽니다. |

앱을 처음 상태로 돌리려면 ⚙ 설정 > **처음부터 다시 설정**을 누릅니다. 시트의 내용은 바뀌지 않습니다.

## 보안과 저장 위치

- 앱은 내 컴퓨터에서 구글과 직접 통신합니다. 중간에 거치는 서버가 없습니다.
- 로그인 정보는 운영체제의 보안 저장소로 암호화해 둡니다(Mac 키체인, Windows 사용자 계정 암호화).
- 설정 파일 위치
  - Mac: `~/Library/Application Support/GRAYZONE 장부/`
  - Windows: `%APPDATA%\GRAYZONE 장부\`
- 앱의 접근을 끊으려면 [Google 계정 > 보안 > 서드 파티 앱 및 서비스](https://myaccount.google.com/connections)에서
  「GRAYZONE 장부」를 삭제합니다.

예전에 Apps Script 웹앱 버전을 배포했다면, 시트의 **확장 프로그램 > Apps Script > 배포 > 배포 관리**에서 보관 처리하면 됩니다.

## 개발

Node.js 22 이상이 필요합니다.

```sh
cd g-account
npm ci
npm start                  # 앱 실행
npm test                   # 테스트 (Linux 에서 Electron 테스트까지: xvfb-run -a npm test)
bash package.sh            # dist/ 에 zip. Mac 용은 macOS 에서만 (서명 때문)
npm run icons              # build/icon.svg 로 아이콘 다시 만들기
```

GitHub에 올리면 Actions가 테스트하고 Mac·Windows용 zip을 만듭니다(`.github/workflows/g-account.yml`).

**새 버전 내기**: `package.json`의 `version`을 올리고 `CHANGELOG.md` 맨 위에 그 버전의 바뀐 점을 적어 올리면,
Actions가 테스트·빌드 뒤 릴리스 `ledger-v버전`을 만들고 zip 3개와 `latest.json`(크기·SHA-256·바뀐 점)을 올립니다.
설치된 앱은 이 릴리스를 보고 스스로 업데이트합니다. 버전을 올리지 않으면 릴리스는 만들지 않습니다.

| 위치 | 내용 |
|---|---|
| `main.js`, `preload.js` | Electron 창·메뉴. 화면에는 `window.gz.call()` 하나만 열어 줍니다. |
| `app/` | 화면 (HTML·JS, 빌드 단계 없음) |
| `src/core.js` | 장부 시트 규칙: 행 읽기, 연도·월·미수금·부가세 계산, 점검, 넣을 자리, 다음 해 묶음, 쓰기 요청 |
| `src/ledger.js` | 읽기·등록·수정·삭제 |
| `src/sheets.js` | Google Sheets API 호출 |
| `src/auth.js` | 구글 로그인 (브라우저 + 127.0.0.1 임시 주소 + PKCE) |
| `src/store.js` | 설정·토큰 저장 |
| `src/updater.js` | 자동 업데이트: 릴리스 확인, 내려받기·SHA-256 확인, 앱이 끝난 뒤 바꿔 넣기 |
| `scripts/release-manifest.js` | 릴리스에 올릴 `latest.json` 만들기 |
| `scripts/sheet-vat-setup.js` | 시트에 부가세 열·탭을 붙인 한 번짜리 변경(2026-11-17 적용함) |
| `test/` | 가짜 구글(지어낸 장부 데이터)로 하는 테스트 |
